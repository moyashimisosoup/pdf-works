# Soft Outline Workspace UI 正本
更新：2026-10-17

## 見た目
- 背景は単一色 **#FCFBF7**。色付きカード面を乱立させない。
- 主要パネルを、ふっくらした「おにぎり的」な角丸輪郭で囲む。影・グラデーション・光沢なし。
- パネル角丸24px、機能グループ16px、入力/ボタン12px。枠線1px **#D8D0D4**。
- 文字/線画アイコンは **Malbec #351F39**。選択Jacaranda #726A95、主操作Bolivia #709FB0、正常Azul Verde #A0C1B8、補助Ivory #F4E8C1。
- 日本語は**源柔ゴシック系**を第一候補にする。使用/同梱ライセンス確認。PC未導入でもUIが操作不能にならないフォールバックを用意し、外部Webフォント取得を起動時に要求しない。
- ピクトグラムは24px原型、標準20px、約1.8px線幅、丸端・丸接合、単色・線画・中塗りなし。
- 大きいカードの入れ子は避ける。囲むのは**機能のまとまり**であって個々のラベルではない。

## 基準配置（1440×900px）

寸法は設計基準であり、画面幅に応じて可変。
- 左：ページ一覧、サムネイルは選択状態のみ枠を強調。
- 中央：PDFが主役。ズーム・ページ送りの簡潔なツールバー。
- 右：現在のモードに必要な設定のみ。初期はページ編集、次に「切り出し」、後続の「補正/OCR」。
- 狭いウィンドウ：サイドパネルを折りたたみ、中央PDFを優先。**重なり・横スクロールしない**。
- 長い処理では控えめな進捗とキャンセルを明示。

## 切り出し画面
- ROI選択枠は細いJacaranda色の破線。直接ドラッグ・微調整可能。
- 「全ページから切り出す」で別のQtウィンドウへ移動。
- 切り出し一覧は小・中・大、可視タイルだけ描画。クリックで拡大、ダブルクリックで元ページを開く。
- 元ページ番号と編集後ページ位置を混同しない。

## アイコンの運用
- これまでのアイコンボードは見た目の参考正本だが、GitHubに自動転用・再配布はしない。使用する画像の権利とソース品質を確認後にベクター化して追加。
- 現時点ではresources/iconsは受け皿のみ。外部フォント/アイコンを無断同梱しない。

## v5 beta フォント適用と検証（2026-10-17）
- アプリ専用書体に **Zen Maru Gothic** を選定（公式OFL 1.1）。フォントは初回セットアップで取得し、QFontDatabase.addApplicationFontでQtへ登録。Windowsフォント登録や起動時Web取得はしない。
- 太さの比較：やわらか Regular 400／**標準 Medium 500**／くっきり Bold 700。選択はQSettingsに保持。
- 初期推奨：主要操作はMedium 500、アプリ名はBold、説明・ステータスは文字サイズを下げすぎない。Thin/Light 300未使用。
- デザイン上の指標：主要ボタン11pt相当、タイトル16pt、補助表示は10pt相当を下限の目安とし、125%と150%表示倍率で確認。太さの最適値は実機評価で確定し、現段階は仮説。
- ソフトな角丸パネル・オフホワイト背景・線画アイコンは維持し、フォント切替が描画エンジンの負荷を増やさない構成。
