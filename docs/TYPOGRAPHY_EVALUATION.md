# UIタイポグラフィ評価（2026-10-17）

## 前提と目的
旧betaのQt画面はPCにあるフォントを探すだけで、別の端末では想定の丸ゴシックが反映されなかった。新しいbetaはZen Maru Gothicをアプリ専用で読み込み、ユーザーが日本語操作文字の太さを切替できるようにする。

## 評価する3種類

| 設定 | ウェイト | ねらい |
| --- | --- | --- |
| やわらか | Regular 400 | 軽い、柔らかい。補助文字では細すぎる可能性 |
| **標準** | **Medium 500** | 初期値。Soft Outlineと視認性のバランス |
| くっきり | Bold 700 | 低コントラスト環境・細字を見づらく感じる場合 |

全画面が一様に太くなることも過度に強調されるので、最終仕様では見出し・基本操作・補助文字の強弱を別途調整する。初期betaでは全体の太さを切り替えて使用感を調べる。

## Windows実機での比較シナリオ

1. `scripts/install_fonts.py` を実行してからアプリを起動。`書体：Zen Maru` 表示を確認。
2. 「削除」「元に戻す」「別名保存」「次」「ページ一覧」の文字と数字を確認。
3. 文字設定を 400 → 500 → 700 と切り替え、表示される字形・太さの変化を確認。
4. Windows表示スケール100%・125%・150%のいずれかで日本語の判別性・崩れ・省略・ボタン幅を記録。
5. 40ページPDFを表示し、300%ズーム・ウィンドウ操作が引き続き正常に行えるか確認。
6. アプリを終了・再起動し、文字設定の保存とオフライン起動を確認。

## 推奨の合格条件
- フォントの未導入PCでも、初回設定後に同じZen Maru Gothicが表示される。
- 小さい「元に戻す」「削除」やページ番号に識別しづらい線がない。
- 125% / 150%でも文字が切れず、ボタンが押せる。
- 文字ウェイト切替によるPDFレンダリング要求増加や起動時の固まりがない。
- Mediumが好評なら標準に維持。Regularが薄すぎるなら補助表示にもMediumを用い、Boldは見出し・重要操作に限定する。

現在は**仮説に基づくUI設定**であり、ユーザーの視覚評価・フォント起動時間の実測は未完了。
