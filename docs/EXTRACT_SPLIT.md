# 選択ページの抽出と1ページ単位分割（beta, 2026-10-20）

## 操作
1. Ctrl/Shiftでページを選ぶ。現在の編集済みページ順を使用し、元ページ番号で自動並べ替えしない。
2. **選択を抽出**：別名PDFを1ファイルだけ作成。編集中の追加90°回転も反映。
3. **1ページずつ分割**：既存フォルダを指定し、選択したページ数を確認して、各1ページの新しいPDFを保存。
4. 分割名例：`source_page_001_source_008.pdf`（出力順001、元PDFの8ページ）。不明瞭な上書きや削除なし。
5. 既存ファイルが一つでも衝突すれば事前に中止。出力途中で失敗すれば、この一連の操作で新規作成できたファイルだけを消して元ファイルに触れない。
6. 出力は元PDF/編集中PDFと独立。編集履歴とUndoには追加せず、新規PDFだけを生成する。

## 技術・検証
- `core/page_extract.py` は選択位置を編集順の `PageSpec`へ変換、単ページ分割を保護付きで実施。
- 抽出は既存の検証済み`core/export.save_edited_pdf`を再利用。
- `workers/renderer.py` に`extract_selected`、`split_selected`を追加。開いている原本を指定し、spawn workerで実行。Qt UIスレッド上でPDFを編集・保存しない。
- 人工PDFテスト：非連続ページ、回転、編集順、内容、元PDFハッシュ、既存出力衝突、分割途中エラー時の片付け。
- Qt操作：選択ゼロ/処理中のボタン無効化、保存先ダイアログ、分割確認、終了/別ファイルを開く操作の抑止。
