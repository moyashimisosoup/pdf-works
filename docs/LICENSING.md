# ライセンスと配布の未決事項

**現時点では、このリポジトリにソフトウェア利用ライセンス（LICENSE）は追加しない。** 公開GitHubリポジトリであることと、自由に再利用・再配布できることは同義ではない。配布方針が決まるまで、他者の利用権限を推測しないこと。

## 確認対象
- **PyMuPDF**：AGPLv3 / 商用ライセンスの選択肢がある。製品ソースの公開範囲とWindows EXE配布方針に合わせて法的条件を確認する。
- **PySide6 / Qt**：コンポーネントごとのオープンソース/商用ライセンス条件、QtのDLL同梱や告知義務を確認する。
- **丸ゴシックフォント**：源柔ゴシック系を使用する場合、埋込/同梱/再配布をライセンスで確認する。フォントファイル自体を無確認でコミットしない。
- **線画アイコン**：画像生成のモックアップから切り出したデータを直接商用成果物へ流用する前に、利用条件とSVG再制作の確認を行う。

## 決定前のルール
- 新規開発・試験のために第三者データやフォントをGitHubへアップロードしない。
- 公開用EXEを配布する前に依存ライセンス表示・NOTICE・使用条件を確定する。
- ドキュメントは技術方針を示すもので、法的助言ではない。

## フォント採用（確認済み）
Zen Maru Gothicの原著作権者が公開している[OFL.txt](https://github.com/googlefonts/zen-marugothic/blob/main/OFL.txt)を確認。**SIL Open Font License 1.1**の下でソフトウェア同梱は可能。ただし同梱時は著作権表示とライセンス全文を維持する。
- 取得元コミットを `553c872b216d1290e2902a466edcdc9682f0df6a` に固定し、Git blob SHA-1でダウンロード内容を検証する。
- フォントファイルはソースリポジトリにコミットしない。初回設定時に公式リポジトリから取得し、Qtでアプリ専用に登録する。インストール後はネットワークアクセス不要。
- EXE配布時は必ずOFL.txtとともに同梱。フォントとアプリ本体のライセンス条件は分けて扱う。PyMuPDFとQtのライセンス判断は引き続き未決。
