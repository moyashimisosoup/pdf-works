# ブラウザUI試作の位置付け（2026-10-17）

## 用途
外出先のスマートフォンから、色・角丸・浅い立体ボタン・プルダウン・ページ一覧と複数選択の操作感を検討するための**静的HTML UI**。Qt版の置き換えではない。

今回の会話で、24ページの人工サンプル、Ctrl/Shift・タッチ複数選択、抽出/分割/圧縮/文字入れの機能切替を持つ単一HTMLファイルとソースZIPを生成済み。実際のPDFファイルを読み書きしない。

**保存の境界**：本GitHubへはこの方針文書と操作仕様を保存する。生成したHTML・CSS・JavaScriptそのものは現在GitHub未保存。ユーザーへ渡した会話添付ファイルが試作物。レビューして正式採用後に既存リポジトリの `preview/` に格納し、必要ならGitHub Pages公開を別途承認のもと進める。

## 共通化する対象
- デザイントークン：Soft Outlineの配色、角丸、文字ウェイト、ボタンの押下状態
- ページ選択仕様：クリック/Ctrl/Shift/範囲/アンカー/タッチ代替
- 操作フロー：抽出・分割・圧縮・テキスト注記のモード設計

共有しないもの：PDF処理エンジン、Qtの内部レンダリング、HTMLのDOM表現。ライセンス・プライバシー検討なしにブラウザからPDFをサーバへアップロードしない。
