# PDF Works: 条件指定分割（beta、2026-10-20）

## UI
「条件で分割」は現在編集中の**全ページ**を対象とし、既存の「選択を抽出」「1ページずつ分割」と区別する。
- 「指定ページ数ごと」：数値欄へ N を入力。40ページ・5ページごとなら8ファイル。
- 「指定位置で区切る」：区切りたい**編集後のページ番号の後**を昇順のカンマ区切りで入力。10ページなら 3,7 → 1〜3 / 4〜7 / 8〜10。
- 入力変更に応じて出力件数・各ファイルのページ数を表示。無効な値、分割しても1ファイルしかできない場合は確定を無効化。
- ダイアログ確定後、既存の出力先フォルダを選ぶ。キャンセル時は一切の保存を行わない。
- 日本語を含む元ファイル名の前48文字を安全化して先頭へ使用。出力例：`lesson_part_001_pages_001-005.pdf`。末尾番号は元PDF IDではなく編集後の出力順。

## 安全・性能
- Qt GUI上では分割・画像生成をせず、既存spawn PDFワーカー `split_groups` に分割スナップショットと条件を送信。
- 既存の`save_edited_pdf`をグループごとに再利用し、元PDFを変更しない。選択状態・Undo履歴も変更しない。
- すべての出力ファイル名を事前に検査。衝突で処理を中断し、既存ファイルに書き込まない。
- 途中失敗時は今回作られたファイルを削除。プロセス強制終了時の全件ロールバックは未保証なのでユーザー実機では出力先を新規フォルダに分けることを推奨。
- 500ファイルを上限として無制限ファイル生成を防ぐ。分割後のPDFのページ数・文字・回転は人工PDFでテスト。
- Windowsでの長時間・高負荷実機検証はまだ完了していない。
