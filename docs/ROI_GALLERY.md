# ROI切り出しギャラリー（beta）

2026-10-19。実装ブランチ：`feature/native-page-edit-20261017`、Draft PR #1。main未統合。

## 使用の流れ
1. PDFを開き「範囲を選択」で長方形を指定する。
2. 「PNG出力」を押し、空きがあるフォルダを選ぶ。既存PNGの上書きは禁止。
3. 出力が成功すると「切り出し一覧」がモデルレスQtウィンドウで開く。
4. 小・中・大のタイルサイズを切り替え、左側の画像を選ぶと右側に拡大表示。
5. タイルをダブルクリックすると、現在の編集後のページ順に該当する元ページが残っていれば、編集画面へ戻る。
6. ギャラリーを閉じても「一覧表示」で前回の出力を開き直せる。別の成功したPNG出力はギャラリー内容を更新する。

## 性能の考え方
- `ui/roi_gallery.py` が画像を表示範囲から順に読み込み、Qt GUIスレッドで巨大PNG全件を解凍しない。
- QThreadPoolによる画像読込は同時最大3件。プレビューは780×660以下、サムネイルは184×152以下のQImageへ縮小。
- メモリ上に保持するサムネイルは48件まで（L R U）。空の枠は小さな単色書類アイコンで表す。
- ダブルクリック先は「書き出し時の元ページID」で保存。編集画面でページが削除済みなら誤ったページへ飛ばない。

## A4一覧PDFの別名保存（2026-10-20）
- 「PDF保存」ボタンからQt標準の保存先選択を開く。既存ファイル・元PDFへの上書きは拒否する
- ソース画像をPNG出力した順にA4縦・2列×4行で配置。1コマの写真は縦横比を維持し、一覧番号と元ページ番号を印字
- 8件ごと改ページ（40件は5枚）。用紙内の余白を取り、文字が枠からはみ出ない構成
- 生成処理は既存spawnワーカーの `roi_sheet_export`。PDF本体を一時生成し、ページ数の確認後に排他的に出力を確定
- 原PNGに変更を加えず、画像データを一度に全枚メモリへ読込まない。入力画像のPNG署名、画素数、ファイルサイズを検査
- PDF内のキャプションは埋め込みフォント不要のASCII（`Original page N`）を利用。日本語ラベルはフォントライセンス・埋め込み設計を確認してから追加
- **未対応**：ギャラリーからの除外・並び替え、PDF出力キャンセルと進捗率、利用者PCのWindows実機操作
