# 製品仕様：pdf-works v5
更新：2026-10-17｜状態：**設計正本・未実装**

## 1. 目的と非目標
- Windowsで軽く動くPDF整理ツール。まず40ページ前後のスキャンPDFで軽快に動作する。
- ページの回転、削除、並べ替え、保存と、**全ページ共通の指定領域を切り出して一覧化**することを中核とする。
- v5.0ではOCRや機械学習は必須にしない。ページ全体を毎回高解像度化する方式は禁止。
- Word編集や複雑なPDF注釈編集、オンライン同期、PDFの自動修復は非目標。

## 2. ユーザーフロー
1. 「開く」でPDFを選ぶ。元ファイルは読み取り専用で開き、ページ数・サイズ情報を先に表示。
2. 左のサムネイルからページを選択。中央で50〜300%拡大・ドラッグ移動。
3. **ページモード**：回転（左右90°、180°、任意角度）、選択ページ削除、ドラッグ並べ替え、Undo。
4. **切り出しモード**：PDF表示上で1個の長方形をドラッグ指定。範囲は移動・サイズ変更で微調整。
5. 「全ページに適用」で同じ相対領域を切り出し、別のQtウィンドウにタイル一覧を表示。
6. 一覧は小・中・大、クリックで拡大、ダブルクリックで対応元ページへ移動。必要ならページ単位で除外。
7. 「一覧PDFを書き出す」「PNGを書き出す」「編集PDFを名前を付けて保存」は別々の操作。

## 3. ページ編集
- 非破壊の編集状態として、元のページID・表示順・削除状態・回転角度を管理。保存前の元PDFには変更しない。
- 操作は履歴に積み、削除・移動・回転はUndoできる。Redoは後続検討。
- 回転90/180/270°は元の物理的スケールを維持。任意角度は「原寸大（用紙を拡張）／用紙に収める（縮小あり）／余白を切る（端切れあり）」を明示。
- 出力時、ベクターや検索文字を維持できる処理を優先。任意角度回転や画像補正でラスタ化する場合は保存前に警告。

## 4. 共通領域の仕様
- ユーザーが表示ページ上で基準ROI（Region of Interest）を1個選ぶ。
- 記録形式：ページの視覚的な向きを基準とした相対矩形 `(x0,y0,x1,y1)`、各値0〜1。選択領域の正の幅・高さを検証。
- DPIやウィンドウ幅には依存しない。PDF内部のCropBox・回転角・座標系差を変換して利用する。
- 適用対象は現在の編集順の「全ページ」が初期値。選択ページのみも可能。削除済みページは除外。
- サイズ・縦横比が大きく異なるページは警告し、個別確認を促す。相対位置が内容一致を保証するわけではない。
- 画像プレビュー用切り出しは必要矩形だけをレンダリングし、まず低解像度から表示。
- 原則1領域のみ。異なる領域をページごとに記録する機能は後続の候補。

## 5. 切り出し一覧
- 独立したQtの別ウィンドウ（WebViewではない）。サイズ変更・最大化・メインとの行き来が可能。
- 現在の編集順・元ページ番号を区別して明示する。
- 小/中/大タイルに変更可、クリックで拡大ダイアログ。必要時のみフル解像度取得。
- スクロール領域の可視アイテムと近傍だけ生成し、40ページの画像を一度に全解像度保持しない。
- ページ除外と元ページへのジャンプを可能にする。並べ替えを一覧上で行うかは後続検討。

## 6. 出力
- **編集PDF**：明示した「名前を付けて保存」。既定名 `<元名>_edited.pdf`。読み込み中の元ファイルと同一パスは拒否する。
- **一覧PDF**：A4縦、初期値2列×4行=8件/ページ。比率維持、ページラベル付き、切り出し部分が読めるよう余白を調整。
- **画像**：原PDFの指定範囲をページ順にPNG出力。初期解像度200dpi。個別ファイルを選択先フォルダへ保存する。ZIP一括化は後続候補。
- 既存の出力ファイルに同名があればOS標準の確認ダイアログを表示。編集元への上書きは認めない。
- 書き込みは可能なら一時ファイルを経由し、成功時に確定。失敗時の部分生成物を扱えるようエラー表示。
- 書き出し後に実ファイルを開き直してページ数・範囲・順序を検証するテストを設ける。

## 7. 後続機能（v5.1〜）
- v5.1：文字の濃さ、明るさ、コントラスト（画像化の副作用を明示）。
- v5.2：手書き番号OCR、認識範囲・候補・修正・重複/欠番・番号順並べ替え。
- v5.3：ユーザーが確認した番号画像と正解ラベルをローカル蓄積し、学習用と評価用を分離。

## 8. 非機能条件
- 応答性を見た目より優先し、描画・出力・OCRがUIスレッドを塞がない。
- 安定したオフライン動作（外部フォントやネット通信を起動条件にしない）。
- 初期EXEはonedir配布から開始し、他PCでPython不要の起動を実機確認。
- バックグラウンド送信やテレメトリーは初期版に設けない。
