# 変更履歴

## 2026-10-17 v5.0-alpha（実機確認前）

- PySide6の独立Qtウィンドウによる閲覧専用PDFビューアを新規実装。
- PDF読み込み、ページ切替、50〜300%表示、スクロールを追加。
- PyMuPDF描画を別プロセスに分離し、画面表示領域だけを描画。
- サムネイル遅延表示と古い画面描画要求のスキップを導入。
- プライベート文書を使わない人工PDF生成スクリプトと5件のバックエンドテストを追加。
- Windows Qt GUIの実機確認・EXE化・ページ編集・切り出しは未実施。

## 2026-10-17 v5.0-beta開発ブランチ（GUI実機未検証）

- 非破壊のページ編集状態（回転90°単位、削除、上下移動、Undo）を追加。
- PyMuPDFによる元PDFを上書きしない別名保存を追加。保存は別プロセスで実行し、内容を再読込して検証。
- アプリUIに編集バーと保存ボタンを追加。Windows実機のGUI操作は未確認。
- バックエンドの軽量CIを追加し、Actionsの結果を待って検証する。
- 連続操作の性能・別端末での耐久性・任意角度回転・ドラッグ並べ替えは未確認または未実装。

## 2026-10-17 UIフォント改善（betaブランチ）
- Zen Maru Gothic Regular/Medium/Boldのローカル読込を追加。アプリ用フォントは初回セットアップで公式固定リビジョンから取得し、整合性を検証。
- 文字ウェイトの400/500/700切替と設定保持、現在のフォント読込状態表示を追加。
- 起動時は選択したウェイトのみ読み込み、使っていないウェイトは後から遅延登録。
- Windows Qt GUIでの視認性・性能評価は未確認。既存alphaの操作性が変わらないかテストを要する。
