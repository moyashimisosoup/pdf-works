# A/B縮尺合わせ（採点用PDFの位置・倍率補正）

目的：採点システムが要求する見本Bと同じ用紙寸法・位置に、スキャンした取り込み側Aを合わせる。**扱うのはAとBの1組だけ**。既存のページ編集とは独立したQtダイアログです。

## 使い方

1. PDF Worksの上部にある **「A/B 縮尺合わせ」** を押す。
2. **A｜取り込み側（調整対象）** と **B｜見本（固定）** をそれぞれPDFから選択する。
3. 「左右に並べる」と「半透明で重ねる」を切り替える。重ね表示のAの不透明度は10〜90％で調整できる。比較用の表示は各PDFの1ページ目。
4. 「倍率」（30.0〜300.0%、0.1%刻み）、「X」「Y」（±100mm、0.1mm刻み）を調整する。初期100％は、Aの1ページ目をBの1ページ目へ縦横比を維持して収めた倍率。Xの正方向は右、Yの正方向は下。
5. 「調整済みAを別名保存」で**Aだけ**新しいPDFへ出力する。Bは変更されず、出力にも含めない。

Aが複数ページのPDFの場合、**Aの全ページに同じ物理的な倍率・移動量**を適用する。出力は全ページがBの1ページ目と同じ用紙サイズになる。Bの2ページ目以降は参照しない。複数ファイルの一括処理・テンプレート保存・自動位置合わせは今回の対象外。

## 技術と安全性

- PyMuPDFの`show_pdf_page`で配置する。PDF内の文字・画像をページの画像に焼き込まず、検索可能な文字は可能な範囲で維持する。画面プレビューだけ低解像度でレンダリングする。
- 描画と保存はQt UIスレッドではなく、専用のspawn PDFワーカープロセスで行う。画面の倍率/位置変更はワーカーを毎回再起動せず、読み込んだプレビューをQt上で再合成する。
- 元A・元B・既存の出力ファイルは上書きしない。USBへの保存でも使えるWindowsの非上書き確定処理を再利用する。
- **Aにリンク・注釈・フォーム・電子署名・添付がある場合は情報を失う危険があるため、保存処理を拒否する。** パスワード保護PDFも不可。Bは参照表示のみ。
- **100％は模範解答への完全一致を自動保証しない。** 用紙の物理サイズと内容の位置を画面で照合し、必要なら倍率/XYを細かく調整する。スキャナー固有の非線形な歪みや縦横別の伸縮は補正しない。
- 学校の答案・模範解答はローカルのみに保持する。GitHub・外部サービスへのアップロードは禁止。自動テストは人工PDFだけを使用。

## 未確認事項

人工PDFの自動試験と利用者の実スキャン/採点ナビでの受入は異なる。実際の採点ナビ取り込み結果と、細い罫線や位置決めマークの一致は利用者Windows PCで確認する。
