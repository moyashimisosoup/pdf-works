# v4系からv5への移行方針

## 背景
v4系はHTML + Python HTTPサーバー + ブラウザ/pywebview/Edgeアプリモード等の方式を試行。回転・並べ替え・OCR・文字補正が存在したが、特に独立ウィンドウ版で実機フリーズ/応答なしが繰り返された。

## 移行の判断
- **v4コードを無検証でv5にコピーしない。** UIと処理を切り分け、最小の安定したQtビューアから再構築する。
- 前版のUXで合意済みのSoft Outlineデザインと、機能要件を仕様として引き継ぐ。
- PyMuPDFの回転・画像生成等の単体アルゴリズムは参考にできるが、適切なライセンス・スレッド/プロセス安全性のレビュー後に個別移植する。
- 起動時のGoogle Fonts読み込み、WebView埋め込みに依存しない。
- 初期版ではOCRや濃度補正の依存を含めず、切り出しが完成してから追加する。

## 旧版の扱い
- v4のZIP配布物は本リポジトリへ自動アップロードしない（容量、ライセンス、動作信頼性、ソース差分の確認が未完了）。
- 必要時、監査済みのソースのみ `legacy/` 等に隔離して移行可能。
- このリポジトリの主要開発対象は**新規のv5**。過去版の機能実装を完了済みとして表示しない。

## 安全な移行順序
空ウィンドウ→PDF描画→ページ編集→ROI抽出→一覧と出力→文字補正→OCR。各段階でWindows実機により応答性を判定する。
